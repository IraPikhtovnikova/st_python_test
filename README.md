## Как запустить

1. Установить зависимости в виртуальном окружении 
```
pip install -r requirements.txt
```
2. Запустить 1 часть
```
python run_1.py 
```
3. Запустить 2 часть (внутри вызываются 3 разных запроса с задержкой в 30сек)
```
python run_2.py 
```
